Lukora Developer API Reference

Integrate bot management and automated deployments using Lukora REST APIs.

1. Upload Bot Script
POST https://lucky-saas-host.onrender.com/api/upload_bot
Content-Type: multipart/form-data
Payload: file: "my_bot.py" (.py, .js, .php, .sh)
2. Launch Bot Instance (24x7 Watchdog)
GET https://lucky-saas-host.onrender.com/api/bot_action/<bot_id>/start
Response: { "success": true, "msg": "Bot launched 24x7" }
3. Stop Bot Instance
GET https://lucky-saas-host.onrender.com/api/bot_action/<bot_id>/stop
Python Integration Example:
import requests

session = requests.Session()
# 1. Login
session.post("https://lucky-saas-host.onrender.com/api/login", json={"username": "dev", "password": "pass"})

# 2. Upload and Launch
with open("my_bot.py", "rb") as f:
    session.post("https://lucky-saas-host.onrender.com/api/upload_bot", files={"file": f})
print("✅ Bot deployed to Lukora Cloud!")
